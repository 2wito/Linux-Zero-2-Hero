# Linux Hebrew 0 to Hero

מדריך חינמי בעברית ללימוד לינוקס, מאפס ועד רמה מתקדמת. יש גם גרסה באנגלית.

A free Hebrew-first guide to learning Linux from zero to hero, with an English version.

## Development

```bash
npm install
npm run dev      # http://localhost:3000 (Hebrew) and /en (English)
npm run ci       # lint + tests + production build
```

See `docs/PLAN.md` for the syllabus, design system and build phases, and `CLAUDE.md` for project conventions.
