# דיסקים ואחסון

<Callout type="info" title="מה נלמד בפרק">
- כמה מקום פנוי יש: `df -h`.
- מה תופס את המקום: `du -sh`.
- אילו דיסקים ומחיצות יש: `lsblk`.
- מה זו **מערכת קבצים**, ומה זה **mount**.
- מבט ראשון על `/etc/fstab`.
- למה `dd` ו-`mkfs` הן הפקודות שהכי צריך לכבד.
</Callout>

## ארונות, מדפים ומגירות

תחשבו על מחסן:

- **הדיסק** הוא הארון עצמו, החומרה.
- **מחיצה** (partition) היא מדף בארון. אפשר לחלק ארון אחד לכמה מדפים, לשימושים שונים.
- **מערכת קבצים** (filesystem) היא שיטת הסידור על המדף: מגירות, תוויות וקטלוג, שבזכותם אפשר למצוא דברים. בלעדיה, המדף הוא סתם ערימה.
- **mount** (עיגון) הוא חיבור של מדף לעץ התיקיות, כך שתוכלו להגיע אליו דרך נתיב.

בפרק 5 ראינו שבלינוקס יש **עץ אחד**, שמתחיל ב-`/`. אין `C:` ו-`D:` כמו ב-Windows. כל דיסק או מחיצה מתחברים לעץ הזה בנקודה כלשהי, ונראים כמו עוד תיקייה.

## כמה מקום פנוי? `df`

`df` (disk free) מציגה כמה מקום יש בכל מערכת קבצים מעוגנת. `-h` (human) מציגה גדלים כמו `7.6G` במקום מספרי בתים:

<TerminalWindow title="~" user="dana@ubuntu">{`
  $ df -h /
  Filesystem      Size  Used Avail Use% Mounted on
  /dev/sdd       1007G  7.6G  949G   1% /
`}</TerminalWindow>

| עמודה | משמעות |
| --- | --- |
| `Filesystem` | מאיפה זה מגיע (הדיסק או המחיצה) |
| `Size` / `Used` / `Avail` | גודל כולל, בשימוש, ופנוי |
| `Use%` | אחוז התפוסה. **מעל 90% כבר צריך לטפל** |
| `Mounted on` | איפה זה מחובר לעץ |

בלי נתיב, `df -h` מציגה את **כל** מערכות הקבצים. הרשימה ארוכה, כי חלקן וירטואליות (כמו `tmpfs`, שיושבת בזיכרון). `-T` מוסיפה את **סוג** מערכת הקבצים:

<TerminalWindow title="~" user="dana@ubuntu">{`
  $ df -hT / /mnt/c
  Filesystem     Type  Size  Used Avail Use% Mounted on
  /dev/sdd       ext4 1007G  7.6G  949G   1% /
  C:\\            9p    953G  238G  715G  25% /mnt/c
`}</TerminalWindow>

ב-WSL רואים כאן את שני העולמות: הלינוקס יושב על דיסק `ext4`, וכונן `C:` של Windows מעוגן ב-`/mnt/c`, דרך גשר בשם `9p`.

### סוגי מערכות קבצים

| סוג | איפה תפגשו אותו |
| --- | --- |
| `ext4` | ברירת המחדל ברוב הפצות הלינוקס. יציבה ומוכחת |
| `btrfs` | ברירת המחדל ב-Fedora. תומכת ב"צילומי מצב" (snapshots) |
| `xfs` | נפוצה בשרתים, ב-RHEL |
| `vfat` / `exfat` | דיסקי USB וכרטיסי זיכרון. כל מערכת הפעלה קוראת אותם |
| `ntfs` | דיסקים של Windows |
| `tmpfs` | "דיסק" בזיכרון. נמחק בכל הפעלה מחדש |

## מה תופס את המקום? `du`

`df` אומרת **כמה** מקום תפוס. `du` (disk usage) אומרת **מי** תופס אותו:

<TerminalWindow title="~/lab" user="dana@ubuntu">{`
  $ du -sh proj
  54M	proj
  $ du -sh proj/*
  580K	proj/code
  3.1M	proj/docs
  51M	proj/videos
  $ du -sh proj/* | sort -rh
  51M	proj/videos
  3.1M	proj/docs
  580K	proj/code
`}</TerminalWindow>

- `-s` (summary): סכום אחד לכל נתיב, ולא שורה לכל תת-תיקייה.
- `proj/*`: כל תיקייה בנפרד. כך מגלים מי "האשם".
- `sort -rh`: מיון לפי גודל קריא (`-h` יודעת ש-`51M` גדול מ-`580K`), מהגדול לקטן.

הצירוף הזה, `du -sh * | sort -rh`, הוא הכלי הראשון כשהדיסק מתמלא. מריצים אותו, נכנסים לתיקייה הגדולה ביותר, ומריצים שוב, עד שמוצאים את הקובץ.

על תיקייה גדולה, `--max-depth=1` מגבילה לרמה אחת:

<TerminalWindow title="~" user="dana@ubuntu">{`
  $ du -h --max-depth=1 /usr 2>/dev/null | sort -rh | head -5
  6.2G	/usr
  5.1G	/usr/lib
  769M	/usr/share
  160M	/usr/bin
  105M	/usr/libexec
`}</TerminalWindow>

<Callout type="tip" title="איפה מחפשים קודם כשהדיסק מלא">
המקומות הנפוצים: לוגים שגדלו (`/var/log`, וראו את פרק 20), קבצים שהורדתם (`~/Downloads`), המטמון של מנהל החבילות (`sudo apt clean` מנקה אותו בבטחה), ותמונות ישנות של Docker (פרק 24). ו-`find / -size +1G 2>/dev/null` מפרק 14 מוצאת את הקבצים הגדולים במיוחד.
</Callout>

## אילו דיסקים יש? `lsblk`

`lsblk` (list block devices) מציגה את כל הדיסקים והמחיצות, כעץ:

<TerminalWindow title="~" user="dana@ubuntu">{`
  $ lsblk
  NAME MAJ:MIN RM   SIZE RO TYPE MOUNTPOINTS
  sda    8:0    0 388.4M  1 disk
  sdb    8:16   0   186M  1 disk
  sdc    8:32   0     2G  0 disk [SWAP]
  sdd    8:48   0     1T  0 disk /snap
                                 /mnt/wslg/distro
                                 /
`}</TerminalWindow>

- **`NAME`**: שם המכשיר. הקובץ שלו נמצא ב-`/dev` (למשל `/dev/sdd`). זוכרים ש"הכול הוא קובץ"?
- **`SIZE`**: הגודל.
- **`TYPE`**: `disk` הוא דיסק שלם, ו-`part` היא מחיצה.
- **`MOUNTPOINTS`**: איפה הוא מעוגן. `[SWAP]` הוא **זיכרון החלפה**: מקום בדיסק שהמערכת משתמשת בו כשנגמר ה-RAM.

ב-WSL המבנה פשוט במיוחד: כל ה"דיסקים" הם וירטואליים, ובלי מחיצות. במחשב לינוקס רגיל תראו משהו כמו `nvme0n1` (דיסק SSD מהיר) או `sda` (דיסק SATA או USB), ומתחתיהם מחיצות: `nvme0n1p1`, `nvme0n1p2` או `sda1`, `sda2`. בדרך כלל יש מחיצה קטנה בשביל האתחול (מעוגנת ב-`/boot/efi`) ומחיצה גדולה ל-`/`.

`lsblk -f` מוסיפה את סוג מערכת הקבצים ואת ה-**UUID**: מזהה ייחודי לכל מחיצה, שלא משתנה גם אם שם המכשיר משתנה.

## עיגון: `mount` ו-`umount`

כשמחברים דיסק USB למחשב לינוקס עם שולחן עבודה, הוא מעוגן **אוטומטית** (בדרך כלל תחת `/media/dana/`). בשרת, או כשרוצים לשלוט במיקום, מעגנים ידנית.

לראות מה מעוגן איפה:

<TerminalWindow title="~" user="dana@ubuntu">{`
  $ findmnt /
  TARGET SOURCE   FSTYPE OPTIONS
  /      /dev/sdd ext4   rw,relatime,discard,errors=remount-ro,data=ordered
`}</TerminalWindow>

`rw` = קריאה וכתיבה. `errors=remount-ro` = אם יש שגיאה בדיסק, לעבור לקריאה בלבד כדי לא להרוס עוד מידע.

ככה מעגנים ומנתקים דיסק USB (נניח שהוא `sdb1`, לפי `lsblk`):

```bash
sudo mkdir -p /mnt/usb
sudo mount /dev/sdb1 /mnt/usb
ls /mnt/usb
sudo umount /mnt/usb
```

1. יוצרים תיקייה ריקה, **נקודת העיגון**.
2. `mount` מחברת את המחיצה לתיקייה. מעכשיו, מה שבתוך `/mnt/usb` הוא התוכן של הדיסק.
3. `umount` (בלי n!) מנתקת. **תמיד** לפני שמוציאים את הדיסק פיזית, כדי שכל המידע ייכתב אליו עד הסוף.

עיגון דורש הרשאות root:

<TerminalWindow title="~" user="dana@ubuntu">{`
  $ umount /mnt/c
  umount: /mnt/c: must be superuser to unmount.
`}</TerminalWindow>

<Callout type="warning" title="target is busy">
אם `umount` עונה `target is busy`, משהו עדיין משתמש בדיסק. לרוב זה **אתם**: טרמינל שנמצא בתוך התיקייה (`cd ~` פותר), או קובץ פתוח בעורך. אל תמשכו את הדיסק החוצה בכל זאת: קבצים שעוד לא נכתבו עד הסוף עלולים להיפגם.
</Callout>

## `/etc/fstab`: מה לעגן בהדלקה

`/etc/fstab` (filesystem table) היא הרשימה של מה לעגן אוטומטית בכל הדלקה. ב-WSL היא כמעט ריקה, כי WSL מעגנת הכול בעצמה:

<TerminalWindow title="~" user="dana@ubuntu">{`
  $ cat /etc/fstab
  # UNCONFIGURED FSTAB FOR BASE SYSTEM
`}</TerminalWindow>

במחשב לינוקס רגיל תראו שורות כאלה. כל שורה היא מחיצה אחת, עם שש עמודות:

```text title="/etc/fstab"
# <device>                                 <mount point>  <type>  <options>          <dump> <pass>
UUID=c138e3db-5d38-456d-b15c-7ee8817106a1  /              ext4    errors=remount-ro  0      1
UUID=4ddacc49-d363-4594-aff3-29b0c556582d  none           swap    sw                 0      0
```

| עמודה | בדוגמה | משמעות |
| --- | --- | --- |
| device | `UUID=...` | איזו מחיצה. UUID עדיף על `/dev/sda1`, כי הוא לא משתנה |
| mount point | `/` | לאן לעגן |
| type | `ext4` | סוג מערכת הקבצים |
| options | `errors=remount-ro` | אפשרויות. `defaults` מתאים לרוב המקרים |
| dump / pass | `0 1` | גיבוי ישן (תמיד 0), וסדר הבדיקה בהדלקה |

<Callout type="danger" title="טעות ב-fstab = מחשב שלא עולה">
שורה שגויה ב-`/etc/fstab` (UUID לא נכון, סוג שגוי) יכולה לעצור את ההדלקה במצב חירום. לפני עריכה: גיבוי (`sudo cp /etc/fstab /etc/fstab.bak`). אחרי עריכה, **לפני** הפעלה מחדש: `sudo mount -a` מנסה לעגן את כל מה שבקובץ, ותציג שגיאה עכשיו, כשעוד קל לתקן. ובדיסק חיצוני, הוסיפו את האפשרות `nofail`, כדי שהמחשב יעלה גם כשהוא לא מחובר.
</Callout>

## הפקודות שמוחקות דיסקים: `mkfs` ו-`dd`

יש שתי פקודות שאין להן "בטל", ושכדאי להכיר בעיקר כדי לכבד אותן:

- **`mkfs`** (make filesystem) **מפרמטת** מחיצה: יוצרת עליה מערכת קבצים חדשה וריקה. כל מה שהיה עליה נמחק. למשל, `sudo mkfs.ext4 /dev/sdb1`.
- **`dd`** מעתיקה בתים גולמיים ממקום למקום. משתמשים בה, למשל, כדי לצרוב קובץ ISO של לינוקס על דיסק USB: `sudo dd if=ubuntu.iso of=/dev/sdb bs=4M status=progress`. `if` הוא המקור (input file) ו-`of` הוא היעד (output file).

<Callout type="danger" title="dd ו-mkfs: בדקו את שם הדיסק שלוש פעמים">
`dd` עם `of=` שגוי, או `mkfs` על המחיצה הלא נכונה, **מוחקים את הדיסק כולו**, מיד ובלי שאלות. אין סל מחזור ואין `Ctrl+Z`. לכן `dd` זכתה לכינוי "disk destroyer". לפני כל שימוש:

1. הריצו `lsblk` **לפני** שמחברים את הדיסק החיצוני, ו**אחרי**. השם החדש שהופיע הוא שלו.
2. בדקו שהגודל ב-`lsblk` מתאים לדיסק שאתם מחזיקים ביד.
3. ודאו שאין עליו שום דבר שאתם צריכים.

ואם אתם רק רוצים לצרוב ISO, תוכנה גרפית כמו **balenaEtcher** או **GNOME Disks** בטוחה יותר: היא מציגה רק דיסקים חיצוניים.
</Callout>

<Exercise title="מי אכל לי את הדיסק?">
1. כמה מקום פנוי יש במחיצה שבה נמצאת תיקיית הבית שלכם?
2. מה גודל תיקיית הבית שלכם?
3. מהן שלוש התיקיות (או הקבצים) הכי גדולים ישירות בתוכה? כללו גם קבצים ותיקיות מוסתרים.
4. מה סוג מערכת הקבצים של `/`?

<Solution>

```bash
df -h ~
du -sh ~
du -sh ~/* ~/.[!.]* 2>/dev/null | sort -rh | head -3
df -hT /
```

1. `df -h ~` מציגה רק את מערכת הקבצים שבה נמצא הנתיב `~`. העמודה `Avail`.
2. `du -sh ~`.
3. `~/.[!.]*` הם הקבצים המוסתרים (שמתחילים בנקודה), בלי `.` ו-`..`. לרוב, `.cache` היא אחת הגדולות.
4. העמודה `Type`. ברוב ההפצות זו `ext4`, וב-Fedora `btrfs`.
</Solution>
</Exercise>
