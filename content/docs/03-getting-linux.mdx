# איך משיגים לינוקס

<Callout type="info" title="מה נלמד בפרק">
- חמש דרכים להגיע לטרמינל של לינוקס, ומה מתאים לכם.
- התקנה של **WSL** ב-Windows, צעד אחר צעד.
- מה האפשרויות ב-Mac, במכונה וירטואלית ובענן.
- איך לפתוח טרמינל ולוודא שהכול עובד.
</Callout>

## לא צריך למחוק כלום

הרבה אנשים חושבים שכדי ללמוד לינוקס צריך למחוק את Windows. ממש לא.

תחשבו על לימוד נהיגה: לא קונים מכונית ביום הראשון. אפשר לשכור, להתאמן במגרש, או לנהוג ברכב של ההורים. גם ללינוקס יש כמה "מגרשי אימון", וכולם בטוחים למחשב שלכם.

## חמש דרכים, בקצרה

| דרך | מה זה | למי מתאים |
| --- | --- | --- |
| **WSL** | לינוקס אמיתי שרץ בתוך Windows | משתמשי Windows. **ההמלצה שלנו.** |
| **מכונה וירטואלית** | "מחשב בתוך מחשב", עם לינוקס מלא כולל שולחן עבודה | מי שרוצה לראות גם את הממשק הגרפי |
| **שרת בענן** | מחשב לינוקס מרוחק שמתחברים אליו | מי שרוצה לתרגל ניהול שרת אמיתי |
| **Dual Boot** | לינוקס מותקן לצד Windows, בוחרים בהדלקה | מתקדמים שרוצים לעבור לינוקס ביומיום |
| **הטרמינל של macOS** | לא לינוקס, אבל דומה מאוד | משתמשי Mac, כגשר להתחלה |

<Callout type="tip" title="ההמלצה הקצרה">
יש לכם **Windows**? התקינו WSL (ההסבר מיד). יש לכם **Mac**? התחילו מהטרמינל המובנה. כבר יש לכם **לינוקס**? פשוט פתחו טרמינל ודלגו לפרק 4.
</Callout>

## WSL: לינוקס בתוך Windows

**WSL** (Windows Subsystem for Linux) הוא רכיב רשמי של Microsoft. הוא מריץ לינוקס אמיתי, עם הליבה האמיתית, ישר מתוך Windows. בלי לאתחל ובלי לחלק את הדיסק.

צריך Windows 11, או Windows 10 בגרסה 2004 ומעלה.

<Steps>

### פותחים PowerShell כמנהל

לחצו על **התחל**, הקלידו `PowerShell`, לחצו עליו **בקליק ימני** ובחרו **Run as administrator** (הפעלה כמנהל).

### מריצים את פקודת ההתקנה

הקלידו את הפקודה ולחצו <Kbd>Enter</Kbd>:

<TerminalWindow title="Windows PowerShell" prompt=">">{`
  > wsl --install
`}</TerminalWindow>

הפקודה מתקינה את WSL ואת **Ubuntu**, שהיא ההפצה שמותקנת כברירת מחדל. זה לוקח כמה דקות.

### מפעילים מחדש את המחשב

בסוף ההתקנה תתבקשו לאתחל. אחרי האתחול, חלון של Ubuntu ייפתח לבד ויסיים את ההתקנה.

### בוחרים שם משתמש וסיסמה

Ubuntu יבקש **שם משתמש** וסיסמה. השם לא חייב להיות זהה לשם ב-Windows. כדאי לבחור משהו קצר באותיות קטנות באנגלית, למשל `dana`.

<Callout type="warning" title="הסיסמה לא מופיעה כשמקלידים">
כשתקלידו את הסיסמה **לא יופיע כלום** על המסך: לא כוכביות ולא נקודות. זה תקין לגמרי, זו שיטת אבטחה. הקלידו ולחצו <Kbd>Enter</Kbd>. **זכרו את הסיסמה**: נצטרך אותה בכל פעם שמתקינים תוכנה.
</Callout>

### בודקים שהכול עובד

בחלון PowerShell רגיל, הריצו:

<TerminalWindow title="Windows PowerShell" prompt=">">{`
  > wsl -l -v
    NAME      STATE           VERSION
  * Ubuntu    Running         2
`}</TerminalWindow>

- `wsl` היא תוכנת הניהול של WSL.
- `-l` (קיצור של list) מציגה את ההפצות המותקנות.
- `-v` (קיצור של verbose, "מפורט") מוסיפה את המצב והגרסה.

הכוכבית מסמנת את ההפצה שנפתחת כברירת מחדל, ו-`2` אומר שאתם על WSL 2, הגרסה המומלצת.

</Steps>

<Callout type="info" title="רוצים הפצה אחרת?">
הפקודה `wsl --list --online` מציגה את כל ההפצות שאפשר להתקין, ו-`wsl --install -d Debian` (למשל) מתקינה הפצה ספציפית. למדריך הזה Ubuntu מושלמת.
</Callout>

## Mac: הטרמינל המובנה

macOS היא **לא** לינוקס, אבל היא קרובת משפחה: שתיהן בנויות על אותם רעיונות של מערכות Unix. לכן רוב הפקודות בפרקים הראשונים (`ls`, `cd`, `mkdir` ועוד) עובדות ב-Mac כמעט אותו דבר.

ההבדלים מתחילים בפרקים המתקדמים, למשל בהתקנת תוכנות ובניהול שירותים. כשתגיעו לשם, כדאי להריץ לינוקס אמיתי במכונה וירטואלית. ל-Mac יש לזה כלים נוחים כמו **UTM** ו-**Multipass**.

## מכונה וירטואלית

**מכונה וירטואלית** היא מחשב מדומה שרץ כתוכנה בתוך המחשב שלכם. מה שקורה בתוכה נשאר בתוכה, אז אפשר להתנסות בלי חשש.

בקווים כלליים:

1. מתקינים תוכנת וירטואליזציה חינמית, למשל **VirtualBox**.
2. מורידים מאתר Ubuntu קובץ **ISO** של Ubuntu Desktop (קובץ שמכיל את דיסק ההתקנה).
3. יוצרים מכונה חדשה עם לפחות **4GB זיכרון**, **2 מעבדים** ו-**25GB דיסק**.
4. מפעילים את המכונה מקובץ ה-ISO ועוקבים אחרי אשף ההתקנה.

## שרת בענן ו-Dual Boot

**שרת בענן**: ספקי ענן משכירים מחשב לינוקס קטן בכמה דולרים לחודש, ולחלקם יש גם מסלול חינמי. אין לו מסך: מתחברים אליו מהטרמינל עם `ssh`, שנלמד בפרק 16. זו הדרך הכי קרובה לעבודה אמיתית עם שרתים.

**Dual Boot**: מתקינים לינוקס לצד Windows על אותו מחשב. זה נותן את הביצועים הטובים ביותר, אבל ההתקנה משנה את חלוקת הדיסק.

<Callout type="danger" title="לפני Dual Boot: גיבוי">
התקנת Dual Boot נוגעת במחיצות של הדיסק. טעות קטנה עלולה למחוק קבצים. **גבו את כל המידע החשוב לפני שמתחילים**, ואם אתם רק לומדים, העדיפו WSL או מכונה וירטואלית.
</Callout>

## פותחים טרמינל

בחרו את המערכת שלכם (הבחירה תישמר לכל האתר):

<DistroTabs>
<Distro id="wsl">

לחצו על **התחל**, הקלידו `Ubuntu` ולחצו על האפליקציה. אפשר גם להקליד `wsl` בתוך PowerShell.

</Distro>
<Distro id="macos">

לחצו <Kbd keys="Cmd+Space" />, הקלידו `Terminal` ולחצו <Kbd>Enter</Kbd>. ה-prompt ב-Mac נגמר בסימן `%` במקום `$`, וזה בסדר.

</Distro>
<Distro id="ubuntu">

לחצו <Kbd keys="Ctrl+Alt+T" />, או חפשו **Terminal** בתפריט האפליקציות.

</Distro>
</DistroTabs>

עכשיו הקלידו את הפקודה הראשונה שלכם:

<TerminalWindow title="~" user="dana@ubuntu">{`
  $ whoami
  dana
  $ uname
  Linux
`}</TerminalWindow>

- `whoami` ("who am I", מי אני) מציגה את שם המשתמש שלכם.
- `uname` מציגה את שם מערכת ההפעלה. ב-Mac תקבלו `Darwin`, השם של הליבה של macOS.

<Exercise title="הכירו את המערכת החדשה">
בטרמינל שפתחתם, הריצו את שלוש הפקודות `whoami`, `uname` ו-`cat /etc/os-release` (מהפרק הקודם). מה שם המשתמש שלכם, ובאיזו הפצה וגרסה אתם?

<Solution>
התשובות תלויות במחשב שלכם. ב-WSL עם ההתקנה הרגילה תראו בערך כך:

<TerminalWindow title="~" user="dana@ubuntu">{`
  $ whoami
  dana
  $ uname
  Linux
  $ cat /etc/os-release
  PRETTY_NAME="Ubuntu 24.04.3 LTS"
  NAME="Ubuntu"
  VERSION_ID="24.04"
  ...
`}</TerminalWindow>

החלק החשוב הוא `PRETTY_NAME`: הוא אומר את שם ההפצה והגרסה. ב-Mac הקובץ הזה לא קיים, ותקבלו הודעת שגיאה. זה צפוי.
</Solution>
</Exercise>
