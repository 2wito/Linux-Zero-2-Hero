## What you covered along the way

- **Beginner:** what Linux is and how to get it, first steps in the terminal, navigating directories, working with files, and reading documentation with `man`.
- **Intermediate:** permissions and `sudo`, installing software, processes, pipes and redirection, text tools like `grep` and `awk`, finding files, environment variables, networking and `ssh`, and archives.
- **Advanced:** Bash scripts, scheduling with cron and systemd, logs, disks, security, Git, Docker and troubleshooting.

That's a serious toolbox already. Most people who work with Linux every day mainly use the commands you learned here.

## What's next?

### Use Linux every day

The best way not to forget is to use it. Open a terminal even when there's another way: to find a file, rename lots of photos, or check what's taking up disk space. Every time you do, it reinforces what you learned.

### Build something real

A small project teaches more than ten tutorials. A few ideas:

- **Automatic backup:** a script that backs up an important directory, with the date in the name, and runs every night (chapters 17–19).
- **Home server:** a Raspberry Pi or an old computer, with key-based SSH, a firewall and automatic updates (chapters 16 and 22).
- **A project on GitHub:** take code or scripts you wrote, put them in a Git repository, and push them to GitHub (chapter 23). Then try running them in a container (chapter 24).

### Keep learning

- [Practice challenges](28-challenges): 12 challenges at three levels, with hints and solutions.
- [Further resources](29-resources): courses, books, practice sites and communities.
- [The cheat sheet](26-cheat-sheet): every command from the guide in one place, printable too.

Want formal recognition? There are well-known certifications in the field, like LPI's Linux Essentials and LPIC-1, or the Linux Foundation's LFCS. They're not required, but they give you a structured learning path.

### Help others

The best way to make sure you understood something is to explain it to someone else. Help a friend install WSL, answer a question on a forum, or send the guide to someone who's just starting out.

## About the project

The guide was born from a simple wish: that every Hebrew speaker could learn Linux for free, without getting stuck on English terminology. This English version makes the same guide available to everyone else.

- **Completely free**, with no ads and no sign-up. Your progress is saved only in your browser.
- **Real output:** every command output shown in the guide was copied from a real run on <En>Ubuntu 24.04</En>, not written from memory.
- **The code is public:** the site is built with Next.js, and all its code is open to view on GitHub.
- **A community guide**, not the official documentation of any distro or company.

The guide was written by **Itay Twito**, a B.Sc. Computer Science student at HIT (Holon Institute of Technology), for friends, family and the community.
