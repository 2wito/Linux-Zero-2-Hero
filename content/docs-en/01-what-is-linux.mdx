## What is an operating system?

Picture a busy restaurant. There's a kitchen with one oven, a stove and a fridge. Dozens of orders arrive at once. Someone has to decide which dish goes into the oven now, who gets the stove, and where everything goes in the fridge.

That person is the **kitchen manager**. Without them, the cooks would keep bumping into each other.

A computer works the same way:

- The **hardware** (processor, memory, disk, screen) is the kitchen.
- The **programs** (browser, music player, game) are the orders.
- The **operating system** is the kitchen manager: it decides which program gets the processor right now, how much memory each one gets, and how files are stored on the disk.

Windows is an operating system. So is macOS. And so is **Linux**.

## So what is Linux?

In 1991 a Finnish student named **Linus Torvalds** wrote, as a side project, the heart of a new operating system. He called it Linux and published the code for anyone who wanted it.

That heart is called the **kernel**. It's the part that talks directly to the hardware. But a kernel on its own is like an engine without a car: powerful, but you can't drive it anywhere.

To get a complete system, you connect many more parts to the kernel:

- **Basic tools** like the terminal and the commands we'll learn in this guide. Many of them came from a project called GNU.
- A **graphical interface** with windows, menus and a mouse.
- **Programs**: a browser, a document editor, a media player.

<Callout type="tip" title="Kernel vs. complete system">
When people say "Linux", they usually mean the whole system. Strictly speaking, Linux is just the kernel. In the next chapter we'll meet **distributions**: the complete cars built around this engine.
</Callout>

## Linux is already all around you

Maybe you've never installed Linux, but you almost certainly use it every day:

| Where | How Linux is involved |
| --- | --- |
| Android phones | Android is built on the Linux kernel. |
| Websites and apps | Most servers on the internet run Linux. When you browse, a Linux server is probably answering. |
| The cloud | The big cloud services mostly run Linux machines. |
| At home | Routers, smart TVs and security cameras usually run a small version of Linux. |
| Supercomputers | Most of the world's most powerful supercomputers run Linux. |

The reason is simple: Linux is stable, it can be adapted to any device, and it costs nothing.

## Free? How does that work?

Linux is **open source**. That means the "recipe" for the software (the source code) is visible to everyone. You're allowed to read it, learn from it, change it and share it, under the terms of its license.

Think of a grandmother's recipe published online: anyone can cook it, add their own spice and share their version. That's how thousands of programmers and companies around the world have been improving Linux for more than thirty years.

<Callout type="info" title="The mascot">
The Linux mascot is a cute penguin named **Tux**. You'll run into him in lots of places.
</Callout>

## How Linux "introduces itself"

We haven't installed Linux yet (that happens in chapter 3), but here's a first peek. The `uname` command asks the system "who are you?":

<TerminalWindow title="~" user="dana@ubuntu">{`
  $ uname
  Linux
  $ uname -r
  6.8.0-48-generic
`}</TerminalWindow>

- `uname` on its own answers with the kernel's name: **Linux**.
- `uname -r` adds the kernel's **version number**. Yours will probably be different, and that's perfectly fine.

Don't worry if this still looks like magic. In chapter 4 we'll take every part of a command apart.
