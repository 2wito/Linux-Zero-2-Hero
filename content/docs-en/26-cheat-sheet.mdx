# Cheat Sheet

Every command from the guide in one place, grouped by topic. Search by command name or by what it does. Each command has a copy button and a link to the chapter that explains it.

<Callout type="tip" title="Printing">
The print button prints **every** command, without the site's menus. The print dialog can also save it as a PDF.
</Callout>

<Callout type="warning">
Some of these commands delete or change files (`rm -r`, `sed -i`, `find -delete`). Read a command's chapter before you run it.
</Callout>
