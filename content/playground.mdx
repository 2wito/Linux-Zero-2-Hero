## טקסט ופקודות בתוך שורה

פקודה בתוך טקסט: `ls -la /home`, ואחריה פסיק. פקודה להקלדה: <Cmd>sudo apt update</Cmd>, ואז ממשיכים לקרוא.

קיצורי מקלדת: לחצו <Kbd keys="Ctrl+Alt+T" /> כדי לפתוח טרמינל, <Kbd keys="Ctrl+C" /> כדי לעצור פקודה, ו-<Kbd>Tab</Kbd> כדי להשלים שם של קובץ.

הפצה עם מספר גרסה: <En>Ubuntu 24.04 LTS</En> היא בחירה טובה למתחילים.

## בחירת הפצה

בחרו הפצה פעם אחת, וכל הלשוניות באתר יעברו אליה (גם בעמודים אחרים, גם אחרי רענון):

<DistroTabs>
<Distro id="ubuntu">

```bash
sudo apt update
sudo apt install htop
```

</Distro>
<Distro id="fedora">

```bash
sudo dnf install htop
```

</Distro>
<Distro id="arch">

```bash
sudo pacman -S htop
```

</Distro>
</DistroTabs>

קבוצה שנייה, עם WSL ו-macOS. אם בחרתם הפצה שלא מופיעה כאן, תוצג הלשונית הראשונה:

<DistroTabs>
<Distro id="ubuntu">

ב-Ubuntu פותחים טרמינל עם <Kbd keys="Ctrl+Alt+T" />.

</Distro>
<Distro id="wsl">

ב-Windows פותחים PowerShell ומריצים <Cmd>wsl --install</Cmd>.

</Distro>
<Distro id="macos">

ב-Mac לוחצים <Kbd keys="Cmd+Space" />, מקלידים Terminal ולוחצים <Kbd>Enter</Kbd>.

</Distro>
</DistroTabs>

## צעדים

<Steps>

### פותחים טרמינל

לחצו <Kbd keys="Ctrl+Alt+T" />. ייפתח חלון עם שורת פקודה.

### בודקים איפה אתם

הקלידו <Cmd>pwd</Cmd> ולחצו <Kbd>Enter</Kbd>. תראו את התיקייה הנוכחית.

### מציגים את הקבצים

<TerminalWindow title="~">{`
  $ ls
  Desktop  Documents  Downloads
`}</TerminalWindow>

</Steps>

## הודעות

<Callout type="info">
לינוקס הוא **ליבה** (kernel), ומה שאתם מתקינים הוא **הפצה** שבנויה סביבו.
</Callout>

<Callout type="tip">
לחצו על <Kbd>Tab</Kbd> כדי להשלים שמות של קבצים ופקודות.
</Callout>

<Callout type="warning">
הפקודה `sudo` נותנת הרשאות מלאות. קראו כל פקודה לפני שאתם מריצים אותה.
</Callout>

<Callout type="danger" title="לעולם אל תריצו את זה">
הפקודה `rm -rf /` מוחקת את כל המערכת. אין "סל מחזור" בטרמינל.
</Callout>
